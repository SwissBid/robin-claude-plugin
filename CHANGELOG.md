# Changelog

All notable changes to the Robin plugin are documented here.

## [1.0.0] - 2026-08-30

Initial public release of the Robin plugin for Claude Code and Claude Cowork.

### Added
- Six bounded workflow skills: `search-and-show-listings`, `show-recommended-listings`,
  `save-favorite-listing`, `sign-in-to-robin`, `apply-to-listing`, `update-search-profile`.
- Bundled MCP server connection to `https://mcp.hi-robin.ai/v6-claude/mcp`.
